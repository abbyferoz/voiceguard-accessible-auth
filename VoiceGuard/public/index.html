Screen-reader-aware protection for sign-in

VoiceGuard builds the fixes that Broken Access (WWW ’25) recommended and tests them. It tells screen-reader users exactly how a look-alike link differs from the real site, never lets one push hide another, speaks a code word that ties each push to its sign-in, and spots push-spam.

💻 Participant computer

Mail, bank sign-in and the browser’s spoken output.

📱 Participant phone

Push approvals. Open it on a real phone to use VoiceOver or TalkBack.

🕶️ Attacker console

Send look-alike emails, race a concurrent login, spam pushes.

🧪 Experimenter

Participants, counterbalanced blocks, scripted tasks, questionnaires.

📊 Results

Automated evaluation and study outcomes, baseline against VoiceGuard.

Quick demo (5 minutes)

  1. Open Computer and Phone side by side and press Start on each.
  2. In Experimenter, open “Advanced” and set the condition to Baseline.
  3. Phishing: in Attacker, send a repetition email, then tab to the link on the computer. Both domains sound the same.
  4. Concurrent login: arm the attack, then sign in to the bank from the computer. Only the attacker’s push is left on the phone.
  5. Fatigue: start spamming and keep pressing Deny.
  6. Switch the condition to VoiceGuard and repeat: you get the phonetic difference, a blocking page, both pushes with code words, and a locked Approve.
